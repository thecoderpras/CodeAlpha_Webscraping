Web Scraping Project using BeautifulSoup
 Overview

This project showcases the ability to scrape structured data from a public website using Python. The scraped data is then saved to a CSV file for further processing.

The project scrapes quotes and authors from:
 Quotes to Scrape

 Features

Sends HTTP request to webpage

Uses BeautifulSoup to parse HTML structure

Scrapes quote text and authors' names

Supports multiple pages (pagination)

Exports custom dataset (CSV file)

Tech Stack

Python 3

BeautifulSoup (bs4)

Requests

CSV
